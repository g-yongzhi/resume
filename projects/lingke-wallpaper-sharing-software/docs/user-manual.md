# 壁纸网站用户操作手册

## 1. 网站概述

壁纸网站是一个提供高质量壁纸下载的平台，用户可以浏览、下载壁纸，注册成为达人后还可以上传自己的壁纸作品供他人下载。网站支持4K、2K、1080P三种分辨率的壁纸，并提供分类浏览功能。

## 2. 页面功能与操作指南

### 2.1 首页

**功能描述**：
首页是用户首次接触平台的核心界面，承担信息引导、资源展示和快速入口的核心作用，通过简洁直观的设计实现。主要包含：
- 热门壁纸项目展示
- 成功案例展示
- 分类筛选
- 加载更多壁纸

**操作指南**：
1. **进入首页**：
   - 点击导航栏的"首页"按钮可随时返回首页

2. **浏览壁纸**：
   - 首页默认展示热门壁纸项目和成功案例
   - 向下滚动查看更多壁纸
   - 点击"加载更多"按钮加载更多壁纸

3. **分类筛选**：
   - 页面左侧边栏列出了所有壁纸分类
   - 点击某个分类可以筛选出该分类下的壁纸
   - 点击"所有分类"可以重置筛选，显示所有壁纸

4. **查看壁纸详情**：
   - 点击任意壁纸缩略图可以进入该壁纸的详情页面

### 2.2 壁纸详情页

**功能描述**：
- 展示壁纸大图
- 显示壁纸信息（名称、分辨率、上传者、下载次数等）
- 提供下载功能

**操作指南**：
1. **查看壁纸**：
   - 页面左侧展示壁纸大图
   - 鼠标悬停在图片上时会有轻微放大效果

2. **查看壁纸信息**：
   - 页面右侧显示壁纸的详细信息，包括：
     - 原始文件名
     - 上传者用户名
     - 分辨率
     - 下载次数
     - 所属分类（以标签形式展示）

3. **下载壁纸**：
   - 点击"下载壁纸"按钮即可下载原图
   - 下载无需登录，任何访问者都可以下载

### 2.3 登录/注册页面

**功能描述**：
- 用户登录
- 新用户注册

**操作指南**：
1. **登录**：
   - 输入用户名和密码
   - 点击"登录"按钮
   - 登录成功后会自动跳转到首页

2. **注册**：
   - 如果没有账号，点击"没有账号？注册"链接切换到注册表单
   - 输入用户名和密码
   - 点击"注册"按钮
   - 注册成功后会自动登录并跳转到首页

3. **切换登录/注册**：
   - 在登录表单下方点击"没有账号？注册"可以切换到注册表单
   - 在注册表单下方点击"已有账号？登录"可以切换回登录表单

### 2.4 上传壁纸页面

**功能描述**：
- 上传新壁纸
- 选择分辨率和分类

**操作指南**：
1. **登录要求**：
   - 上传壁纸前必须先登录
   - 未登录状态下尝试上传会提示"请先登录"

2. **选择图片**：
   - 点击"选择图片"按钮或直接点击文件输入框
   - 在弹出的文件选择器中选择要上传的图片文件
   - 选择后会显示图片预览

3. **设置壁纸信息**：
   - 选择壁纸分辨率（4K、2K或1080P）
   - 选择壁纸所属分类（可多选，按住Ctrl键选择多个分类）

4. **上传壁纸**：
   - 填写完所有信息后，点击"上传"按钮
   - 上传成功后会显示成功提示
   - 上传失败会显示错误信息

## 3. 常见问题与解答

**Q1: 如何成为达人（上传者）？**
A1: 只需注册账号并登录，即可上传壁纸。本站无需特别申请即可成为达人。

**Q2: 支持哪些图片格式？**
A2: 支持常见的图片格式，如JPG、PNG、GIF等。

**Q3: 壁纸大小有限制吗？**
A3: 单个壁纸文件大小限制为10MB。

**Q4: 如何删除我上传的壁纸？**
A4: 目前暂不支持用户自行删除已上传的壁纸，如需删除请联系网站管理员。

**Q5: 图片无法显示怎么办？**
A5: 请尝试刷新页面，如仍无法显示，可能是网络问题或图片已被删除。

## 4. 使用技巧

1. **快速找到喜欢的壁纸**：
   - 使用分类筛选功能可以更快找到您感兴趣的壁纸
   - 分类标签直观显示，方便快速识别壁纸类型

2. **上传高质量壁纸**：
   - 上传前确保图片分辨率与您选择的选项一致
   - 选择合适的分类，使其更容易被其他用户发现

3. **高效浏览**：
   - 首页采用瀑布流布局，滚动浏览更加流畅
   - 壁纸缩略图悬停时有放大效果，方便预览

## 5. 隐私与安全

1. 本站仅收集必要的用户信息（用户名和密码）
2. 密码经过加密存储，保障账户安全
3. 上传的壁纸将公开展示，请勿上传含有隐私信息的图片
4. 请勿上传侵权或违规内容，否则可能被管理员删除
