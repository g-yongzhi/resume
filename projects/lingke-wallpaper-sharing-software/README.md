# Lingke Wallpaper Sharing Software

灵壳壁纸分享软件项目。项目本地整理版本为 Node.js + Express + MySQL 结构，包含用户、壁纸、分类、上传、下载和后台接口等模块。

## 项目内容

- 用户登录与注册页面
- 壁纸列表、详情、上传页面
- 分类管理与壁纸接口
- MySQL 数据表结构
- 前端静态页面与服务端控制器

## 本地整理版本

本地项目包含 `public/`、`src/`、`docs/`、`database/`、`package.json` 等文件，适合后续拆成独立仓库完整展示。

## 说明

该项目用于展示 Node.js 网站项目整理、接口结构、数据库结构和页面交付能力。
