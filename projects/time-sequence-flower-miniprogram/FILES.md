# 文件清单

当前 GitHub 目录已上传小程序入口文件，便于快速查看项目类型和页面配置。

## 已上传文件

- `README.md`：项目说明
- `app.js`：小程序入口逻辑
- `app.json`：页面路由和底部导航配置
- `project.config.example.json`：微信开发者工具配置示例

## 本地整理版本包含

- `pages/`：首页、目的地、攻略、订单、个人中心等页面
- `components/`：通用卡片、导航和内容组件
- `assets/`：SVG 图标、字体与页面图片
- `data/`：目的地、路线、酒店、美食等演示数据
- `utils/`：日期、存储、格式化等工具函数

如果后续要重点展示这个项目，建议拆成独立仓库并上传完整目录。
