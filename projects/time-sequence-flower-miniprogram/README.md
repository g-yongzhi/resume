# 时序花城小程序

一个以城市花期、旅行目的地和本地攻略为主题的微信小程序。项目包含首页、目的地、景点、美食、酒店、论坛攻略、账单、会员、登录注册等页面，主要展示小程序多页面结构、组件复用和本地数据组织。

公开仓库已移除微信开发者工具私有配置和真实 AppID，保留源码、页面、组件和静态资源。

## 功能模块

- 首页 Banner、热门入口和内容流
- 目的地、景点、花期详情
- 美食、酒店列表与详情
- 论坛攻略和推荐内容
- 旅行账单与支出记录
- 登录注册、个人中心、会员页面
- 自定义 TabBar 和图标组件

## 本地运行

1. 使用微信开发者工具导入项目目录。
2. 复制 `project.config.example.json` 为 `project.config.json`。
3. 将 `appid` 改为自己的测试 AppID，或使用测试号运行。
