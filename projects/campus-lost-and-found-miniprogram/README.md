# 校园失物招领小程序

一个校园失物招领微信小程序原型，围绕物品分类、失物信息展示和首页检索入口组织页面。项目体量较小，适合作为小程序页面布局和交互原型展示。

公开仓库已移除微信开发者工具私有配置和真实 AppID。

## 功能模块

- 首页分类入口
- 失物/招领信息卡片
- 自定义导航栏组件
- 物品分类图片资源
- Skyline / glass-easel 小程序配置

## 本地运行

1. 使用微信开发者工具导入项目目录。
2. 复制 `project.config.example.json` 为 `project.config.json`。
3. 将 `appid` 改为自己的测试 AppID，或使用测试号运行。
