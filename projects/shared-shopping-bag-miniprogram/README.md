# 共享购物袋小程序

一个微信小程序项目，用于演示共享购物袋借还流程。项目包含站点选择、扫码借袋、订单记录、押金/会员、归还确认、个人中心和帮助说明等页面。

本目录为 GitHub 展示版本，已移除微信开发者工具私有配置文件和真实 AppID。

## 功能模块

- 登录入口
- 首页站点状态展示
- 扫码借袋/还袋流程
- 借还订单列表和订单详情
- 押金与会员页面
- 附近站点、帮助中心、个人中心
- 本地 mock 数据和前端状态管理

## 说明

完整工程已在本地整理为 GitHub-ready 版本，公开展示时不上传 `project.private.config.json` 和真实 AppID。
