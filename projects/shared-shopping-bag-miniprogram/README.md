# 共享购物袋小程序

一个微信小程序项目，用于演示共享购物袋借还流程。项目包含站点选择、扫码借袋、订单记录、押金/会员、归还确认、个人中心和帮助说明等页面。

本仓库整理自小程序工程目录，已移除微信开发者工具私有配置文件和真实 AppID。公开仓库中提供 `project.config.example.json` 作为导入参考。

## 功能模块

- 登录入口
- 首页站点状态展示
- 扫码借袋/还袋流程
- 借还订单列表和订单详情
- 押金与会员页面
- 附近站点、帮助中心、个人中心
- 本地 mock 数据和前端状态管理

## 目录结构

```text
.
├── assets/              # 图标和静态资源
├── config/              # 小程序配置
├── mock/                # 演示数据
├── pages/               # 页面
├── services/            # 数据服务
├── utils/               # 工具方法
├── app.js
├── app.json
└── app.wxss
```

## 本地运行

1. 使用微信开发者工具导入项目目录。
2. 复制 `project.config.example.json` 为 `project.config.json`。
3. 将 `appid` 修改为自己的测试 AppID，或使用测试号运行。

## 说明

当前版本以小程序前端流程和本地 mock 数据为主，适合用于展示页面组织、业务流程拆分和小程序工程结构。
