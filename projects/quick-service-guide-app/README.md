# Quick Service Guide App

快速服务指南 Android 应用项目。项目本地整理版本为 Kotlin + Jetpack Compose 结构，包含城市服务事项、分类、搜索、详情页和资料展示等模块。

## 项目内容

- Android 原生项目结构
- Kotlin / Jetpack Compose 页面
- 首页、事项详情、个人中心等页面
- 本地数据仓库与页面组件
- Gradle 构建配置

## 本地整理版本

本地项目包含 `app/`、`gradle/`、`build.gradle.kts`、`settings.gradle.kts`、`gradlew` 等文件，后续适合拆分为独立仓库完整展示。

## 说明

该项目用于展示 Android 应用项目整理、移动端页面实现和交付归档能力。
