# Lingke Studio Website

灵壳工作室官网项目。项目本地整理版本为 React + Vite + Express 结构，包含官网展示、案例页、联系表单和后台接口相关文件。

## 项目内容

- 官网首页与案例展示页面
- 前端组件与页面路由
- Express 服务端入口
- 联系表单与基础接口结构
- 静态资源与案例图片

## 本地整理版本

本地已整理完整项目目录，包含前端源码、服务端源码、配置文件和图片资源。由于该项目图片素材较多，完整资源包适合通过 GitHub 网页上传或拆分为独立仓库。
