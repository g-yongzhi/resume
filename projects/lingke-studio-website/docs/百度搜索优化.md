# 百度搜索：灵壳 / 网站定制开发 等关键词

> 站点：https://lkqt.top/  
> 站长平台：https://ziyuan.baidu.com/

SEO **不能一夜见效**。品牌词「灵壳」通常 1～4 周；竞争词「网站定制开发」「软件开发」往往要 **数月 + 持续内容**，且与竞价、老站权重有关。

---

## 一、服务器必做（与代码一起上线）

### 1. 生产环境 `.env` 确认

```env
VITE_SITE_URL=https://lkqt.top
VITE_BAIDU_SITE_VERIFICATION=你的百度验证码
```

改完后在服务器执行：`npm run build` 并重启 Node。

### 2. 推送代码并部署

与平时一样：Cursor 提交推送 → 宝塔 WebHook 或手动 `git pull` + `npm run build`。

---

## 二、百度搜索资源平台（按顺序点）

### 1. 站点验证

- 已添加站点 **lkqt.top** 的话，用 **HTML 标签验证**  
- 把验证码填进服务器 `.env` 的 `VITE_BAIDU_SITE_VERIFICATION`，重新 build 部署  
- 回到百度点 **完成验证**

### 2. 提交 sitemap

- 左侧 **普通收录** → **sitemap** → 提交：  
  `https://lkqt.top/sitemap.xml`  
- 部署成功后可在浏览器打开该地址，应看到 XML 列表

### 3. 提交首页（加快收录）

- **普通收录** → **手动提交** → 资源提交 → URL：  
  `https://lkqt.top/`

### 4. 绑定熊掌号 / 智能小程序（可选）

非必须；有企业资质可提升品牌展示。

### 5. 每周做一次

- **索引** 里看收录量是否增加  
- **流量与关键词** 看是否出现「灵壳」「网站定制」等展现  
- 新案例页上线后，可再提交对应 URL 或依赖 sitemap 自动抓取

## 三、站内已做的技术优化（代码里）

| 项 | 说明 |
