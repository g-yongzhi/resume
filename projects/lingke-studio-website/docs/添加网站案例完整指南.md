# 添加一个新案例（最短版）

做三件事：**放图 → 加案例数据 → 加首页卡片**。不用改路由。

---

## 1. 放图

把截图放到：`public/cases/英文名文件夹/cover.png`  
代码里要写：`/cases/英文名文件夹/cover.png`（**有开头的 /**，不要写 public）

---

## 2. 加案例数据

打开 **`src/data/workCases.ts`**，在 **`WORK_CASES`** 数组里**照抄一条现有案例**（如西安华海酒店），整段复制后改：

- `slug`：英文小写，例如 `my-hotel` → 子页地址就是 `/work/my-hotel`
- `heroTitle`、`liveUrl`、`coverImage`：必改
- 其余文案按需改；配色改 `palette` 四个 `#` 颜色，或删掉手写 `palette` 只保留一行 **`paletteFromCover: true`** 让页面从封面自动取色（图必须在本站 `public` 里）

保存文件。

---

## 3. 加首页卡片

打开 **`src/components/SelectedWork.tsx`**，在 **`PROJECTS`** 里**照抄一条**带 `detailPath` 的，改：

- `id`：不要和别人重复
- `title`、`line`、`image`
- **`detailPath`：必须是 `/work/` + 你的 `slug`**

`filter` 网站案例写 **`web`**。保存。

---

## 检查

终端里 `npm run dev`，看作品区有没有新卡片、点进去是否正常。

**常见问题：** 图裂了 → 路径要和磁盘上 `public` 里一致；点进去跳回首页 → `slug` 和 `detailPath` 对不上，或 `WORK_CASES` 里没这条。

---

想查每个字段的详细含义：看 **`src/data/workCases.ts`** 文件最上面的注释。
